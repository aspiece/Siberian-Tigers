# Publish the Siberian Tigers website

The site is a static page in `index.html`. No build or installation is required.

## Enable GitHub Pages

1. Open https://github.com/aspiece/Siberian-Tigers/settings/pages
2. Under Build and deployment, set Source to **Deploy from a branch**.
3. Choose **main** and **/ (root)**, then Save.
4. Wait for GitHub Pages deployment to finish, then open https://aspiece.github.io/Siberian-Tigers/

## QR code

The Share section contains a QR code pointing to the permanent site URL above. Its image is served by QRServer, an external service. Open the high-resolution QR link and save the image for printing. Before printing copies, scan the code with a phone and confirm the published page opens.

## Updating the site

Edit `index.html` and commit to main. GitHub Pages will republish it automatically after Pages is enabled. Keep the repository name and owner unchanged to preserve the QR destination.

All nine species are included. Each species links to an official guide with photos. The first version uses typography and graphics rather than embedded species photography. The proposed solution is marked in progress and should be updated when the team develops it.

## Validation

The uploaded source was checked for nine species cards and a mobile viewport. Official species and prevention sources were reviewed. A local Windows sandbox setup error prevented browser preview, interaction testing and QR scanning; review the live site on a phone before distributing the QR code.
